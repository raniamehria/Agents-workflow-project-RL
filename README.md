# Agentic Workflows – LLMOps project

Albert School 2026-2027 course project: fine-tuning a small language model to speak like Yoda, with an end-to-end LLMOps pipeline on Google Cloud.

## Setup

1. Install [uv](https://docs.astral.sh/uv/)
2. Clone this repository
3. Create the virtual environment:

```bash
uv sync
```

4. In VS Code, select the `.venv` Python interpreter (3.11.6)
